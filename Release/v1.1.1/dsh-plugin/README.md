# VK-1 · DSH 余额挂件

把大肥鱼桌宠搬进 DSH：她举着平板显示 DeepSeek 余额，花钱时MC受击，充值时掉米饭盆。

**插件版本：1.1.1** · 维护者：[YCTS-otree](https://github.com/YCTS-otree) · [报告 BUG / 提建议](https://github.com/YCTS-otree/VK-1/issues) · [更新记录](https://github.com/YCTS-otree/VK-1/blob/main/CHANGELOG.md)

本项目由 [VKmich16/VK-1](https://github.com/VKmich16/VK-1) 的 `大肥鱼桌宠改_D-16BVM` 移植而来，作为 DSH bundle 在网页界面中运行。美术、音效与原版行为来自上游；本仓库由原作者授权指定的插件负责人 YCTS-otree 维护，负责 DSH 插件实现及兼容。

> **移植版的问题请在本仓库反馈。** 请勿到原作者仓库提交 DSH 插件 BUG，以免打扰桌宠原版的维护。

## 安装

最简单的方式，是让 DSH 给自己安装插件。

1. 打开 DSH，将工作区设为 **DSH 目录**。
2. 对 DeepSeek 说：

   > 安装这个插件：https://github.com/YCTS-otree/VK-1

3. 安装后点击“立即启用”。支持热加载的 DSH 可直接加载；若提示需要重启，再重启 `dsh web`。同名插件升级需先卸载登记再安装新版，浏览器已有脚本是否自动替换取决于外观管理器。

DSH 需要已配置 `DEEPSEEK_API_KEY` 凭据。插件通过 DSH 凭据服务读取，不需要额外的平台会话令牌，也不用把 Key 发到聊天里。

<details>
<summary>给安装 agent 的说明 / 手动安装</summary>

可安装的 bundle 位于 `dsh-plugin/`。请把这个子目录的绝对路径交给 `plugin_manager` 的 `install_bundle`，同时登记 profile 依赖和 `dsh.bundles`。

手动管理 profile 时，依赖与 bundle 配置示意如下。需要合并进现有配置，勿覆盖其他插件：

```json
{
  "dependencies": {
    "dsh-vk1-balance-widget": "link:<仓库绝对路径>/dsh-plugin"
  },
  "dsh": {
    "bundles": ["dsh-vk1-balance-widget"]
  }
}
```

通过现有 DSH profile 的包管理流程解析依赖，再重启 Web 服务。仅运行 `dsh plugin --profile web add <dsh-plugin 绝对路径>` 不会完成 bundle 登记，推荐仍让 DSH 的安装工具处理。

独立发布包在 `Release/v1.1.1/dsh-plugin/`，也可交给同一个安装工具。

</details>

## 能做什么

- **余额平板**：显示 DeepSeek 余额，支持手动刷新；接口短暂抖动时尽量保留上次读数，宿主接口缓存 8 秒。
- **逐分扣费**：每下降 0.01 元播放一次红闪、震动、飘字与打击音效，间隔 0.2 秒，单轮最多排队 40 次。
- **充值掉饭盆**：饭盆自由落下、弹跳，可以拖动；拖到角色身上才完成入账动画。
- **铁盆与表情**：吃完饭留下铁盆，从上方落到头上可以堆叠，双击头部逐个取下；四种表情随状态切换。
- **火控雷达**：饭盆闲置 10 秒后触发锁定，随后磁吸入账。
- **位置与外观**：拖动定位、边缘吸附、位置记忆、右侧镜像和滚动条避让；菜单可调大小、声音和音量，也可演示扣费和充值。

## 1.1.0 · 现代化功能同步

对齐上游 2026-10-15 的 `571da3b`（`大肥鱼桌宠现代化改_D-16BVM（2026）`），保留 DSH bundle 安装与宿主凭据接口。

- **抚摸**：不按鼠标键，在角色上持续划动。累计 24px 并持续划动 0.5 秒后播放五帧手部动画；停下 0.15 秒结束。点击或拖动立即中止，安定后再允许触发；头上有盆时先逐个取下再抚摸。
- **铁盆堆叠**：每次喂饭都能留下铁盆；把铁盆从上方落到头上或盆堆上即可戴住。拖着或静止放置不会直接戴盆。双击头部每次取下最上面一个；饭盆碰到角色即可喂食。
- **四页设置**：右键角色 → 设置，分为显示、声音、音效库、演示。可选跟随系统 / 浅色 / 深色；掉盆、抚摸和扣费效果可分别关闭。关闭掉盆后新充值直接入账，关闭扣费效果仍正常更新余额。
- **四类音效**：掉血、回血、铁盆落头、双击取盆各有独立音量，保留总音量与静音；新增上游两种铁盆音效。
- **本地音效库**：导入浏览器可解码的音频（单文件最大 50 MB），查看波形、按秒裁剪、调整增益、试听、命名、保存使用或恢复出厂。音频存储在当前浏览器的 IndexedDB，不上传服务器；浏览器禁用存储时仍可用出厂音效。清除站点数据会移除自定义音效。
- **今日消费**：根据观察到的真实余额变化估算，充值与演示不计入，可按平台今日消费校准。跨日重置；未运行期间未观察到的充值和消费可能无法区分，不能替代平台账单。
- **峰谷时钟**：双击平板，或通过菜单显示北京时间、峰谷标记和倒计时。离开角色 5 秒恢复余额；服务器提供时间时优先校时。沿用上游 00:30–08:30 谷时规则，不含节假日调整，非实时价格承诺。
- **独立演示**：支持自定义扣费次数和充值金额。演示数字与真实结算隔离，手动刷新清除演示与未领取饭盆。

## 与桌宠原版的区别

| 项目 | DSH 插件版 | 桌宠原版 |
| --- | --- | --- |
| 运行位置 | DSH Web 页面内 | 独立桌面窗口 |
| 余额凭据 | DSH 凭据服务 | 原桌宠自己的配置流程 |
| 吸附范围 | 网页窗口边缘 | 原生桌面窗口范围 |
| 桌面置顶与托盘 | 无 | 由桌面版实现 |
| 反馈入口 | [本仓库 Issues](https://github.com/YCTS-otree/VK-1/issues) | [原作者仓库](https://github.com/VKmich16/VK-1) |

## 版本与开发

插件版本以 `dsh-plugin/package.json` 为准，规范化基线为 **1.0.0**（前身版本为 0.2.0），当前维护版本为 **1.1.1**。新增功能递增 MINOR，修复和小改进递增 PATCH，MAJOR 由维护者决定。

上游 **v11** 是原有移植基线，**2026 版**为新增来源；两者与插件版本无关。宿主入口现为 `index-v12.js`：后缀用于绕开 Loader 旧模块缓存，更新宿主代码时必须递增。

使用已有 Node.js 与 npm，无需安装额外依赖：

```sh
npm --prefix dsh-plugin run check
npm --prefix dsh-plugin run preview
npm --prefix dsh-plugin run release
```

离线检查覆盖语法、宿主入口、素材路由、页面脚本注入去重、卸载清理，以及结算、演示隔离、开关、抚摸触发、堆叠、消费记录、音频裁剪和设置恢复，不读取个人凭据、不访问真实余额接口。UI 变更仍需在 DSH 中检查拖拽、缩放、动画和外观切换。

`preview` 在 `http://127.0.0.1:4317` 提供真实 bundle 注入和素材路由的模拟余额页面，可离线验证界面、充值、扣费与卸载重挂载；不访问真实账号。当前验证范围见 [tools/VALIDATION.md](https://github.com/YCTS-otree/VK-1/blob/main/tools/VALIDATION.md)。

发布工具输出 `Release/v<版本>/dsh-plugin/` 与 SHA-256 清单，已有版本目录拒绝覆盖。推荐使用 1.1.1 或更新版本；1.0.0/1.0.1 的历史 SHA-256 清单受 Windows 换行影响，不作为完整性校验依据。版本更新同步 README 和 CHANGELOG。见[维护规则](https://github.com/YCTS-otree/VK-1/blob/main/AGENTS.md)和[贡献说明](https://github.com/YCTS-otree/VK-1/blob/main/CONTRIBUTING.md)。
