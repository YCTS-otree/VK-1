# 收件人请看这里（Quick start）

一个贴在桌面上的小挂件：角色举着一块黑屏平板，平板上显示 DeepSeek 余额。余额每下降 0.01 元，角色就红闪 + 震动 + 播放打击音效，头顶飘出 -0.01（0.2 秒一次，飘出的数字会串成一条）。

她还会换表情、会被铁盆扣头、会自动收走没人领的米饭盆 —— 详见下面。

## 怎么用

1. 把整个文件夹放到任意目录（路径里有中文也没关系，但请不要放在只读位置）。别只拿走启动器，同目录的图片和音效都是必需的。
2. 双击  启动DSH余额宠物.vbs
3. 第一次启动会弹一个框让你填 DeepSeek API Key（sk- 开头）。填完确定即可；不想填就取消，挂件会先离线待着（屏幕显示 --）—— 之后随时右键 →「设置 API Key」补上。如果你已经装了 DSH，Key 会被自动读取，不弹框。
4. 挂件出现在屏幕左下角，默认 大杯 = 454 × 454 像素。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 左键按住拖动角色 | 移动；松手后自动回到屏幕左下角 |
| 左键按住米饭盆拖动 | 把盆拖到角色身上就喂给她：盆消失 → 头顶冒爱心 → 这笔充值一次性入账 |
| 左键按住铁盆拖动 | 铁盆也能拖，还能扣在她头上（见下面「铁盆怎么玩」） |
| 双击她的头 | 头上扣着铁盆时：她弹一下，铁盆消失 |
| 右键 | 菜单：立即刷新余额 / 测试扣费 / 测试充值动画 / 演示连续扣费 / 尺寸 / 声音 / 设置 Key / 退出 |
| 双击托盘图标 | 手动触发一次扣费动画 |

「立即刷新余额」= 平板立刻对齐到最新余额（不补播动画）。后台每 2 秒自动查一次；余额一有变化就一分钱一分钱地扣，每次都有完整的动画 + 音效。

有人给你充钱时，屏幕右边会掉下一盆米饭，屏幕数字先不动；把它拖到角色身上（碰到头发也算）才会加上去，同时飘一个绿色的 +3.00。不拖就永远不加 —— 所以你想什么时候「收钱」都行。想先看效果又不花钱：右键 → 测试充值动画 → 模拟充值 3 元（掉米饭盆）。

想看连续扣费的效果：右键 → 演示连续扣费 → 选 -0.1 之类，就会以 0.2 秒一次连着扣 10 次给你看。

嫌吵就右键 → 声音 → 取消「开启声音」，或把音量调到 0 %（立刻生效，会记住）。

## 她有哪些表情

她会自己换脸，你不用管：

| 表情 | 什么时候 |
| --- | --- |
| 开心 | 平时都是这张 |
| 紧张 | 正在扣费的时候（扣完还会保持 1 秒） |
| 傲娇 | 米饭盆放了 10 秒还没喂她 |
| 冷脸 | 铁盆扣在她头上的时候 |

> 铁盆在头上时扣费她也保持冷脸；只有新的米饭盆掉下来才会让她重新开心。

## 铁盆怎么玩

米饭盆被她吃掉的地方，会掉出一个铁盆。

- 铁盆不值钱、也不能吃，纯玩具，随便拖
- 拖到她头上（或者干脆扔到她头顶），它就会扣在她头上 → 她变冷脸，还会顶着盆一起抖
- 双击她的头 → 她弹一下，铁盆消失
- 铁盆同时只有一个，不会越堆越多

## 米饭盆上的绿色框框（火控雷达）

有米饭盆的时候，盆周围会出现一个绿色方括号 + 一排数字，那是「目标名牌」，会实时显示：

| 读数 | 含义 |
| --- | --- |
| 距离 | 盆离她多远 |
| 接近率 | 盆在靠近（正数）还是远离（负数） |
| 相对高度 | 正数 = 盆比她高，负数 = 比它低 |
| 下面的圈 | 一根指针，指向盆相对她的方位 |

这个框不用管它，它只是显示。但有件事要注意：

米饭盆落地后 10 秒还没喂她，就会被自动吸走吃掉。

如果你一次充了好几笔、掉了一地盆：只要有一个满 10 秒，所有的盆会一起被吸走。所以想慢慢喂就抓紧点，或者一个一个来。

想提前看看这个名牌长什么样（不喂也不会被吸）：右键 → 测试充值动画 → 打开火控雷达。

## 遇到问题

双击 vbs 没反应 / 杀软报警

这个挂件用 Windows 自带的 PowerShell 写界面，.vbs 启动器只是用来隐藏黑框，偶尔会被杀软误报。改成双击  启动（调试窗口）.cmd，它会保留一个黑窗口把错误显示出来。

屏幕一直显示 --

余额没取到。看同目录的 pet.log：每次请求的结果都记在里面。出现 node not found → 装一个 Node.js（LTS 版即可），程序会先试系统自带的 .NET，失败才用 Node，两者都不行就取不到余额；出现 HTTP 401 → Key 不对，右键 →「设置 API Key」换一个。

掉下来的盆我没喂，它自己没了

那是 10 秒到了被自动收走的（见上面「火控雷达」那段）。这是正常行为。

没有铁盆掉出来

确认文件夹里有 iron_bowl.png；缺了它这个玩法会自动跳过。

卡顿 / 托盘图标消失

右键 → 退出，再重新启动一次即可。

## 关于

这是一个独立的桌面小程序（不是 DSH 插件）：它自己是一个进程，只从 %USERPROFILE%\.dsh\.credentials.yaml 读取 API Key，其余和 DSH 没有任何耦合，所以 DSH 关掉它也照常运行。

它不联网上传任何数据，只访问 DeepSeek 官方的余额查询接口。
