# DSH 余额宠物 (v11)

一个能贴在桌面上的小挂件：角色举着一块纯黑屏幕的平板，屏幕上实时显示你的 DSH（DeepSeek）余额。余额每下降 0.01 元，角色就红闪一下 + 轻微震动，同时播放一次打击音效，头顶弹出红色的 -0.01 向上飘并渐隐。

余额上升（充值）时，屏幕右侧会掉下一盆米饭，把它拖到角色身上才会入账。

这一版新增了三件事：

- 四种表情 —— 她会根据状态换脸（见第五节）
- 铁盆 —— 米饭盆被吃掉后会掉一个铁盆，可以扣在她头上（见第六节）
- 火控雷达 —— 有米饭盆时会出现目标名牌，10 秒不喂就自动吸走（见第七节）

## 一、启动

1. 把整个文件夹放到任意目录（路径里有中文也没关系，但请不要放在只读位置）。别只拿走启动器，同目录的图片和音效都是必需的。
2. 双击  启动DSH余额宠物.vbs
3. 角色出现在屏幕左下角（默认 大杯 = 454 × 454 像素），平板上几秒后显示余额。
4. 开机自启：按 Win + R 输入 shell:startup，把 vbs 的快捷方式丢进去。

前提：Windows PowerShell 5.1（系统自带）+ Node.js（建议保留，理由见下）。

API Key 会自动读取 %USERPROFILE%\.dsh\.credentials.yaml 里已有的 DEEPSEEK_API_KEY；读不到时会弹出输入框让你填（分享给别人时对方就用这个入口）。

> 为什么建议保留 Node：取余额走两条路 —— 先试 .NET，失败再改用 Node。有些机器上 .NET 拿不到 TLS 凭据（SEC_E_NO_CREDENTIALS），这时就只剩 Node 这一条路。两条路的结果都会写进 pet.log，所以出问题时先看日志就能知道走了哪条。

### 充值：掉米饭盆

云端余额上升时（有人给你充了钱），程序不会直接改屏幕上的数字，而是：

- 从屏幕右边缘丢下一盆米饭，让它自由落体 + 弹跳（弹几次取决于掉落高度，最多 3 次）。
- 屏幕数字保持不动，等待你去拿。
- 用左键把盆拖到角色身上（碰到头发 / 头饰也算）→ 盆消失、头顶冒像素爱心、这笔充值一次性加到屏幕上，同时飘一个绿色的 +x.xx。
- 不拖就永远不加。盆可以一直躺在屏幕底部。

可以同时有多个盆（一笔充值一个盆）。它们彼此有碰撞体积、落点会错开，不会叠成一堆。每个盆都带自己的目标名牌（见第七节），任一个盆满 10 秒没被领取，所有的盆会一起被吸走。

## 三、扣费的节奏

步长固定为 0.01 元，不再可调。这是刻意的设计：

- 0.01 是接口报数的最小单位，所以永远不会有「凑不满一格的零头」，也就从根上排除了「数字动了但没播动画」这类问题。
- 每次扣费之间间隔 0.2 秒，每次都完整播放红闪 + 震动 + 音效 + 飘字。间隔短了之后，飘出的数字会像连击那样向上错开排成一条串，不会叠在一起看不清。

规则：云端余额一有变化，就把差额换算成 N 个 0.01，然后一个一个地扣。

> 例：余额从 30.00 变成 29.95（少了 0.05）→ 连续扣 5 次 -0.01，屏幕数字 30.00 → 29.99 → 29.98 → 29.97 → 29.96 → 29.95，每一次都有完整的红闪 + 震动 + 音效 + 飘字，间隔 0.2 秒，五个 -0.01 依次向上串成一条。

数字绝不会在没动画的情况下变化：数字只在扣费那一帧变化，而且一次只变 0.01。

「实时」指的是延迟小：服务器那边余额一变，下一次轮询（默认 2 秒）就把它换算成扣费次数，第一次扣费当帧就会弹出，不会压着等下一轮。

> 大额跳变的保护：一次最多排队 40 次（0.40 元），避免云端一次性跳很多时动画播上好几分钟。剩下的部分会在后续轮询里继续补完。

## 五、表情差分：她会换脸

角色有四张脸，程序按当前状态自动切换：

四张表情，文件名固定为 sprites\expression_*.png

| 表情 | 什么时候出现 |
| --- | --- |
| 开心（张嘴笑） | 默认状态。空闲、有盆在场、刚喂完，都是这张 |
| 紧张（闭眼 + 汗） | 扣费动画播放时。扣完之后还会保持约 1 秒才收回 |
| 傲娇（波浪嘴） | 米饭盆满 10 秒还没被领取的时候 |
| 冷脸（面无表情） | 铁盆扣在她头上的时候（见第六节） |

### 优先级（从高到低，第一个命中的生效）

```
1. 铁盆在头上 且 场上没有活的米饭盆   -> 冷脸
```

```
2. 扣费动画正在播 / 刚播完的保持期     -> 紧张
```

```
3. 米饭盆满 10 秒未领取               -> 傲娇
```

```
4. 其余                               -> 开心
```

两条容易搞混的规则，这里说清楚：

- 冷脸压过紧张：铁盆扣在头上时，即使正在扣费她也保持冷脸。只有新的米饭盆掉下来才会让她重新开心起来。
- 紧张压过傲娇：盆满 10 秒变傲娇之后，如果这时发生扣费，她会先变紧张，扣完再回到傲娇（盆还在场上、还是没人喂）。

## 六、铁盆：米饭盆的「后事」

米饭盆被她吃掉的那一瞬间，会在盆消失的那个位置掉出一个铁盆。

两个盆尺寸同源，落地后走同一套物理（下落、弹跳、拖拽）

铁盆和米饭盆一样：可以拖来拖去、有弹性（Q 弹）、有惯性、会弹跳。但它有三点不同：

- 不带钱 —— 它纯粹是个道具，拖到哪都不会让余额变化
- 不能被吃 —— 你把它拖到她身上，它只会掉下去，不会消失
- 不会被火控雷达锁定 —— 名牌永远只认米饭盆（见第七节）

### 把它扣到她头上

两种方式都行：拖着铁盆放到她头上，或者把铁盆扔到她头顶让它自己落下去。

只要盆沿落到头的位置，它就会扣在她头上：

- 她的表情变成冷脸，而且这种状态下继续扣费也保持冷脸（见第五节）
- 盆会跟着她一起震、一起 Q 弹（它是贴在她身上的实物）
- 盆沿会挡住穿出来的发箍和呆毛（不然会从盆里穿模出来）

### 拿下来

双击她的头（点两下）：她会再弹一下，铁盆渐隐消失，立绘恢复正常，表情回到正常流程（开心 / 紧张 / 傲娇，看当时的状态）。

> 铁盆同时只会有一个：已经有一个在场（或扣在头上）时，吃掉下一个米饭盆不会再掉新的，免得两个盆叠在一起。

## 七、火控雷达：目标名牌

场上有米饭盆时，盆的周围会出现一个《战争雷霆》风格的目标名牌（绿色方括号 + 一排读数）：

名牌的各个部分（示意图，几何比例与程序里的实际绘制一致）

| 读数 | 含义 |
| --- | --- |
| 距离 | 盆离角色多远，单位 kpx（千像素） |
| 接近率 | 盆正在靠近还是远离：正数 = 靠近，负数 = 远离，单位 px/s |
| 相对高度 | 正数 = 盆比角色高，负数 = 比角色低，单位 px |
| 方向环 | 环上一根指针，指向盆相对角色的方位（可旋转） |

方括号的大小跟着米饭盆的大小走，盆被拖着移动时名牌也跟着走。

### 自动锁定与吸附

米饭盆落地后 10 秒还没被领取，就会发生：

1. 名牌锁定（出现方括号）。
2. 再过 1 秒，盆开始被加速吸向角色。
3. 吸到身上 → 自动走一次完整的「喂食」（加钱 + 爱心 + 音效）。

吸附是缓缓加速的（不是一把抓走），从锁定到吃掉大约 0.5 – 1.5 秒，取决于盆离得多远。

### 多个盆：一起锁定，一起吸走

不管场上有几个盆，只要有一个满 10 秒，所有的盆都会被锁定。

比如你连着充了三次，掉了三个盆：

```
第 1 个盆掉下 -> 等 2 秒 -> 第 2 个盆掉下 -> 再等 8 秒，什么都不做
```

```
^ 此时第 1 个盆已经满 10 秒
```

结果：三个盆同时出现方括号，然后一起被吸过去。刚掉下来 2 秒的那个盆不会再自己等 10 秒。

### 想手动看看名牌

右键 → 测试充值动画 → 打开火控雷达。它只是把名牌提前亮出来给你看读数，不会缩短倒计时、也不会启动吸附。自动流程照常在自己的时间点锁定并吸走。

## 八、分享给别人（或公开分享）

要发整个文件夹，不能只发启动程序。启动器只是个外壳，真正干活的是同目录下的 dsh_pet.ps1 + sprite.png + sprites\ + rice.png + iron_bowl.png + hit.mp3 + feed.mp3；少一个都会缺图或缺音效。

如果你要转发或公开这一份，先删掉这几样（它们只属于你本人）：

| 文件 | 为什么不能发 |
| --- | --- |
| apikey.txt | 里面是你的 API Key |
| pet.log / error.log | 运行日志，含你的余额数值与路径 |
| state.ini | 你调过的尺寸与音量，对方不需要继承 |

脚本里没有写死任何绝对路径或用户名（用的是脚本自身所在目录、%USERPROFILE%），所以对方解压到任何目录都能直接用。

对方第一次启动时会弹出输入框让他填自己的 API Key（因为他多半没装 DSH，程序找不到 .dsh\.credentials.yaml）；取消也能用，只是先离线显示 --，之后右键菜单随时补填。

## 九、换图 / 换音效 / 换表情 / 改屏幕位置

换立绘：重新生成贴图，并打印黑屏四角坐标

```
powershell -ExecutionPolicy Bypass -File .\make_sprite.ps1 -Source "新图路径"
```

把打印出的四角填进 dsh_pet.ps1 里 Relayout() 的 qx / qy（1024 贴图坐标系）即可。

换表情：把四张 sprites\expression_*.png 换成你自己的脸即可（尺寸随意，程序会缩放）。四张图的文件名和用途是固定的：

| 文件名 | 用途 |
| --- | --- |
| expression_11.png | 开心（默认） |
| expression_12.png | 傲娇（盆 10 秒未领） |
| expression_21.png | 冷脸（铁盆扣头） |
| expression_22.png | 紧张（扣费中） |

换音效只要把新文件命名为 hit.mp3 覆盖，或设 DSHPET_SOUND_FILE。换铁盆素材设 DSHPET_IRON_FILE（换成没有透明边距的图效果最好；有边距也能用，程序会自动裁）。

### 常见问题

角色不出现 / 一闪而过

用 启动（调试窗口）.cmd，再看 error.log 与 pet.log。

没有声音

看 pet.log：正常会有 sound ready: ... volume=80。sound pool failed = 音效文件缺失或被占用；sound: nothing played = 系统 MCI 打不开该 mp3，换一个试试。静音：右键 → 声音 → 取消「开启声音」，或音量调 0 %；也可设 DSHPET_SOUND=0，或删掉 hit.mp3。

掉了米饭盆但数字不变

这是设计如此：必须用左键把盆拖到角色身上才会入账。如果盆根本拖不动，看 pet.log 里有没有 bowl landing: / bowl thrown / bowl placed 记录。

屏幕一直显示 --

余额没取到。看 pet.log：node not found = 装 Node.js 或设 DSHPET_NODE；HTTP 401 = Key 不对，右键「设置 API Key」换一个。屏幕角落出现红点 = 当前离线。

铁盆没掉出来

确认同目录有 iron_bowl.png；缺了它程序会静默跳过（看 pet.log 有没有 iron art failed）。

目标名牌不出现

名牌只在有米饭盆的时候出现。另外它要求表情差分已加载（sprites\ 目录存在）；把那四张图补上即可。

红闪太强 / 太弱

用记事本打开 dsh_pet.ps1，找到 double maxTint = Math.Max(0.30, 0.64 - _scale * 0.75); 改 0.30 和 0.64 这两个数即可。

## 十一、改脚本前必读

这些 .ps1 文件是故意写成纯 ASCII 的（界面上的中文用 C# 的 \uXXXX 转义）。因为 Windows PowerShell 5.1 在没有 BOM 时按 ANSI 读取脚本，直接写中文会乱码甚至解析失败。要改脚本请只写英文，中文用 \uXXXX 转义；改说明文档这类文件请用支持 UTF-8 的编辑器。

## 十二、想微调节奏与手感

步长固定 0.01、间隔固定 0.2 秒（刻意不可调，理由见第三节）。真要改，只能改源码常量（在 dsh_pet.ps1 顶部附近，只写英文）：

| 常量 | 默认 | 含义 |
| --- | --- | --- |
| StepYuan | 0.01 | 每次扣多少 |
| CueGapSec | 0.2 | 两次扣费之间的间隔 |
| MaxCuesPerPoll | 40 | 单次轮询最多排队多少次 |
| BowlWaitSec | 10.0 | 米饭盆多久没人领就锁定（秒） |
