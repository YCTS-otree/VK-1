# v1.1.0 验证记录 · 2026-10-16

上游功能来源：VKmich16/VK-1 的 `571da3b21b202ecf4fd54635c2adb4a73d3d8bd1`，目录 `大肥鱼桌宠现代化改_D-16BVM（2026）`。

环境：Windows、已有 Node.js 24.19.0 / npm 11.17.0；无额外运行依赖。

## 自动检查

`npm --prefix dsh-plugin run check` 包含：

- JS 语法、bundle 入口、全部素材路由、脚本注入去重及不误判正文中的路径。
- 宿主路由清理，页面全局事件监听器卸载。
- 使用本地响应桩验证余额缓存与服务器时钟持续前进，不发出真实请求。
- 真实扣费结算、充值领取、刷新重同步，演示充值与真实余额和消费记录隔离，重复领取保护。
- 关闭掉盆后立即入账、关闭扣费特效后继续结算、关闭抚摸后不触发。
- 静止不触发抚摸、持续划动及正常事件间隔触发、停下后结束、拖动安定阻断。
- 多铁盆、按戴上顺序堆叠、一次只取顶盆、静止放置不戴盆。
- 饭盆拖动接触即喂食并释放抓取，今日消费扣除充值、设置和消费持久化。
- 四页设置渲染，峰谷时钟自动恢复，PCM WAV 按指定区间裁剪及增益。
- 当前发布目录存在时检查文件清单及 SHA-256。

行为测试在隔离 DOM 适配器中执行实际 widget.js，测试入口只在测试内存副本中注入，不写入发布脚本。

## 浏览器检查

通过 `npm --prefix dsh-plugin run preview` 使用 bundle 的真实 tapIndex 注入与素材路由，余额接口替换为固定模拟值：

- 1280×720 与 390×844 视口，浅色 / 深色设置、控件换行、滚动与关闭入口。
- 实际显示余额、抚摸五帧合成及底边平板可见性。
- 四路音量，导入已公开的 hit.mp3、波形、0.04–0.16 秒裁剪、试听、命名保存和刷新后恢复。
- 充值、喂饭、双铁盆堆叠和双击逐个取盆，双击平板时钟、拖动定位与镜像，卸载后重新挂载保持一个挂件；检查浏览器错误日志。

## 验证边界

本轮未连接运行中的 DSH 外观管理页面，未访问真实凭据或余额接口。模拟宿主验证不能替代目标 DSH 版本的安装与外观切换集成测试；原有“切换外观后可能需要 F5”限制仍保留。

今日消费基于观察到的余额变化，无法重建运行前的真实账单；峰谷时钟沿用上游固定时段，不提供节假日日历或实时价格数据。原生窗口、托盘及桌面诊断工具不属于插件维护范围。
